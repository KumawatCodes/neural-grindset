# How This Course Works

> **Read this first before touching any other file.**

## The Learning Philosophy

This course is designed as a **dependency graph**, not a linear list. Each topic builds on previous ones. Skipping ahead causes confusion — trust the order.

## How to Use These Files

1. **Follow the phase order** (Phase 1 → Phase 2 → ...). Do not jump.
2. **Each file has a `Prerequisites` section** — if you haven't covered those, stop and go back.
3. **Each file has a `When to Skip` section** — use this if you already know the topic.
4. **Each file has a `Projects This Enables` section** — this tells you why you're learning it.

## The 6 Phases

| Phase | Name | Duration | Goal |
|-------|------|----------|------|
| 1 | **Foundation** | 3-4 weeks | Be comfortable with terminal, Git, Python |
| 2 | **Data Core** | 4-5 weeks | Query databases, model data, understand pipelines |
| 3 | **Big Data** | 4-5 weeks | Scale beyond single machine with Spark |
| 4 | **Streaming & Real-Time** | 3 weeks | Build event-driven pipelines |
| 5 | **Production & Cloud** | 4-5 weeks | Deploy, monitor, govern data systems |
| 6 | **Architecture & Design** | 3-4 weeks | Design systems from scratch, interview ready |

## The Golden Rule

> **If you feel confused about "where does this fit?", you skipped a prerequisite.**

Go back one file. The confusion is a signal, not a flaw.
