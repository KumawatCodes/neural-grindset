## SECTION 1 — Theory (Viva)

### What is Big Data?

- Data that is too large, fast, or complex for traditional tools to process
- Requires distributed storage and parallel processing frameworks

### The V's of Big Data

|V|Meaning|Example|
|---|---|---|
|Volume|Amount of data|Petabytes of social media posts|
|Velocity|Speed of data generation/processing|Stock prices, sensor streams|
|Variety|Different types of data|Text, video, JSON, logs, images|
|Veracity|Accuracy and trustworthiness of data|Fake news, sensor errors|
|Value|Business value extracted from data|Insights, predictions|

**Velocity vs Veracity (Viva):**

- Velocity = how fast data arrives and must be processed (real-time streams)
- Veracity = how reliable and accurate the data is (noisy, incomplete, inconsistent data)

### Components of Hadoop

|Component|Role|
|---|---|
|HDFS|Distributed file system — stores data across cluster|
|MapReduce|Distributed processing framework — parallel computation|
|YARN|Resource management — allocates CPU/RAM to jobs|
|Common|Shared libraries and utilities used by all components|

### What is MapReduce?

- Programming model for processing large datasets in parallel across a cluster
- Breaks job into two phases: Map (parallel processing) and Reduce (aggregation)
- Fault tolerant: failed tasks automatically re-executed
- Inspired by functional programming: map() transforms, reduce() aggregates
- Developer writes only Map logic and Reduce logic — framework handles rest

### What is MPP (Massive Parallel Processing)?

- Processing technique where many processors work simultaneously on different parts of the same task
- MapReduce implements MPP — multiple Mappers run in parallel on different data splits
- Enables processing of terabytes/petabytes by dividing work across hundreds of nodes
- Contrast with single machine processing which is sequential and limited by hardware

### Components of YARN Model (Viva Question)

**ResourceManager (Master):**

- One per cluster
- Two sub-components:
    - Scheduler: allocates CPU+RAM (Containers) to applications — no monitoring, pure allocation
    - ApplicationsManager: accepts job submissions, launches ApplicationMaster per job

**NodeManager (Worker — on every node):**

- Manages resources on its own node
- Launches and monitors Containers
- Reports resource usage to ResourceManager

**ApplicationMaster (one per job):**

- Runs inside a Container on a worker node
- Negotiates resources from ResourceManager
- Coordinates task execution on NodeManagers
- Handles task-level failures

**Container:**

- Unit of resource allocation (CPU cores + RAM)
- Actual Map/Reduce tasks run inside Containers
- Dynamically allocated — no fixed slots like Hadoop v1

### MapReduce Data Flow (Detailed)

```
Input File (HDFS)
      |
  InputFormat (splits file into logical splits)
      |
  RecordReader (converts each split to key-value pairs)
      |
  Mapper (user logic — transforms input key-value to intermediate key-value)
      |
  Combiner (optional local reducer — reduces data before shuffle)
      |
  Partitioner (decides which Reducer gets which key — hash(key) % numReducers)
      |
  Shuffle and Sort (framework moves data to correct Reducer, sorts by key)
      |
  Reducer (user logic — aggregates grouped key-value pairs)
      |
  OutputFormat (writes result to HDFS)
      |
  Output Directory (HDFS)
```

## SECTION 3 — Program 1 : Word Count (Most Important)

### What it Does

- Input: text file with sentences
- Mapper: splits each line into words, emits (word, 1) for each word
- Reducer: sums all 1s for same word, emits (word, total_count)

### Input File Example

```
hello world hello hadoop
hadoop is great
hello world
```

### Expected Output

```
great   1
hadoop  2
hello   3
is      1
world   2
```

### Code — File: `WordCount.java`

```java
package com.bigdata;

import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;
import java.io.IOException;
import java.util.StringTokenizer;

public class WordCount {

  public static class TokenizerMapper extends Mapper<Object, Text, Text, IntWritable> {
    private final IntWritable one = new IntWritable(1);
    private Text word = new Text();
    public void map(Object key, Text value, Context context)
        throws IOException, InterruptedException {
      StringTokenizer itr = new StringTokenizer(value.toString());
      while (itr.hasMoreTokens()) {
        word.set(itr.nextToken());
        context.write(word, one);
      }
    }
  }

  public static class IntSumReducer extends Reducer<Text, IntWritable, Text, IntWritable> {
    private IntWritable result = new IntWritable();
    public void reduce(Text key, Iterable<IntWritable> values, Context context)
        throws IOException, InterruptedException {
      int sum = 0;
      for (IntWritable val : values) sum += val.get();
      result.set(sum);
      context.write(key, result);
    }
  }

  public static void main(String[] args) throws Exception {
    if (args.length != 2) {
      System.err.println("Usage: WordCount <input> <output>");
      System.exit(-1);
    }
    Configuration conf = new Configuration();
    Job job = Job.getInstance(conf, "word count");
    job.setJarByClass(WordCount.class);
    job.setMapperClass(TokenizerMapper.class);
    job.setCombinerClass(IntSumReducer.class);
    job.setReducerClass(IntSumReducer.class);
    job.setOutputKeyClass(Text.class);
    job.setOutputValueClass(IntWritable.class);
    FileInputFormat.addInputPath(job, new Path(args[0]));
    FileOutputFormat.setOutputPath(job, new Path(args[1]));
    System.exit(job.waitForCompletion(true) ? 0 : 1);
  }
}
```

## SECTION 4 — Program 2 : Sum of Even Numbers

### What it Does

- Input: text file with numbers (one per line or space separated)
- Mapper: emits (even, number) only if number is even
- Reducer: sums all even numbers

### Input File Example

```
2 3 5 8 10
4 7 6 9
11 12 14
```

### Expected Output

```
even    56
```

### Code — File: `SumEven.java`

```java
import java.io.IOException;
import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.IntWritable;
import org.apache.hadoop.io.LongWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class SumEven {

    // MAPPER
    // Input:  key = line offset, value = line of space-separated numbers
    // Output: key = "even" (Text), value = even number (IntWritable)
    public static class EvenMapper
        extends Mapper<LongWritable, Text, Text, IntWritable> {

        private Text evenKey = new Text("even");

        @Override
        public void map(LongWritable key, Text value, Context context)
            throws IOException, InterruptedException {

            String[] tokens = value.toString().trim().split("\\s+");

            for (String token : tokens) {
                try {
                    int num = Integer.parseInt(token.trim());
                    if (num % 2 == 0) {
                        context.write(evenKey, new IntWritable(num));
                    }
                } catch (NumberFormatException e) {
                    // skip non-numeric tokens
                }
            }
        }
    }

    // REDUCER
    // Input:  key = "even", values = list of even numbers
    // Output: key = "even", value = sum of all even numbers
    public static class EvenReducer
        extends Reducer<Text, IntWritable, Text, IntWritable> {

        @Override
        public void reduce(Text key, Iterable<IntWritable> values, Context context)
            throws IOException, InterruptedException {

            int sum = 0;
            for (IntWritable val : values) {
                sum += val.get();
            }
            context.write(key, new IntWritable(sum));
        }
    }

    // DRIVER
    public static void main(String[] args) throws Exception {
        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "Sum of Even Numbers");

        job.setJarByClass(SumEven.class);
        job.setMapperClass(EvenMapper.class);
        job.setReducerClass(EvenReducer.class);

        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(IntWritable.class);

        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
```

## SECTION 5 — Program 3 : Palindrome Check

### What it Does

- Input: text file with words
- Mapper: checks if each word is a palindrome, emits (word, "YES") or (word, "NO")
- Reducer: passes through the result

### Input File Example

```
madam racecar hello level world
radar java python
```

### Expected Output

```
hello   NO
java    NO
level   YES
madam   YES
python  NO
racecar YES
radar   YES
world   NO
```

### Code — File: `Palindrome.java`

```java
import java.io.IOException;
import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.LongWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class Palindrome {

    // MAPPER
    // Input:  line of words
    // Output: key = word, value = "YES" or "NO"
    public static class PalindromeMapper
        extends Mapper<LongWritable, Text, Text, Text> {

        @Override
        public void map(LongWritable key, Text value, Context context)
            throws IOException, InterruptedException {

            String[] words = value.toString().trim().split("\\s+");

            for (String w : words) {
                String word = w.toLowerCase().trim();
                if (word.isEmpty()) continue;

                String reversed = new StringBuilder(word).reverse().toString();
                String result = word.equals(reversed) ? "YES" : "NO";

                context.write(new Text(word), new Text(result));
            }
        }
    }

    // REDUCER
    // Just pass through — key = word, value = YES/NO
    public static class PalindromeReducer
        extends Reducer<Text, Text, Text, Text> {

        @Override
        public void reduce(Text key, Iterable<Text> values, Context context)
            throws IOException, InterruptedException {

            // Take first value (all values for same word are same result)
            for (Text val : values) {
                context.write(key, val);
                break;
            }
        }
    }

    // DRIVER
    public static void main(String[] args) throws Exception {
        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "Palindrome Check");

        job.setJarByClass(Palindrome.class);
        job.setMapperClass(PalindromeMapper.class);
        job.setReducerClass(PalindromeReducer.class);

        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(Text.class);

        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
```

## SECTION 6 — Program 4 : Factorial (Most Important)

### What it Does

- Input: text file with numbers (one per line)
- Mapper: computes factorial of each number, emits (number, factorial)
- Reducer: passes through result

### Input File Example

```
5
6
3
7
```

### Expected Output

```
3   6
5   120
6   720
7   5040
```

### Code — File: `Factorial.java`

```java
import java.io.IOException;
import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.LongWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class Factorial {

    // MAPPER
    // Input:  one number per line
    // Output: key = number (Text), value = factorial result (Text)
    public static class FactorialMapper
        extends Mapper<LongWritable, Text, Text, Text> {

        // Helper: compute factorial of n
        private long computeFactorial(int n) {
            if (n == 0 || n == 1) return 1;
            long result = 1;
            for (int i = 2; i <= n; i++) {
                result *= i;
            }
            return result;
        }

        @Override
        public void map(LongWritable key, Text value, Context context)
            throws IOException, InterruptedException {

            String line = value.toString().trim();
            if (line.isEmpty()) return;

            try {
                int num = Integer.parseInt(line);
                long factorial = computeFactorial(num);
                context.write(new Text(String.valueOf(num)),
                              new Text(String.valueOf(factorial)));
            } catch (NumberFormatException e) {
                // skip non-numeric lines
            }
        }
    }

    // REDUCER
    // Pass through — mapper already computed factorial
    public static class FactorialReducer
        extends Reducer<Text, Text, Text, Text> {

        @Override
        public void reduce(Text key, Iterable<Text> values, Context context)
            throws IOException, InterruptedException {

            for (Text val : values) {
                context.write(key, val);
                break;
            }
        }
    }

    // DRIVER
    public static void main(String[] args) throws Exception {
        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "Factorial");

        job.setJarByClass(Factorial.class);
        job.setMapperClass(FactorialMapper.class);
        job.setReducerClass(FactorialReducer.class);

        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(Text.class);

        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
```

## SECTION 7 — Program 5 : Armstrong Number

### What it Does

- Input: text file with numbers (one per line)
- Armstrong number: sum of each digit raised to the power of number of digits = number itself
- Example: 153 → 1³ + 5³ + 3³ = 1 + 125 + 27 = 153 ✓
- Example: 370 → 3³ + 7³ + 0³ = 27 + 343 + 0 = 370 ✓
- Mapper: checks if number is Armstrong, emits (number, "YES/NO")
- Reducer: passes through

### Input File Example

```
153
370
371
123
9474
100
```

### Expected Output

```
100     NO
123     NO
153     YES
370     YES
371     YES
9474    YES
```

### Code — File: `Armstrong.java`

```java
import java.io.IOException;
import org.apache.hadoop.conf.Configuration;
import org.apache.hadoop.fs.Path;
import org.apache.hadoop.io.LongWritable;
import org.apache.hadoop.io.Text;
import org.apache.hadoop.mapreduce.Job;
import org.apache.hadoop.mapreduce.Mapper;
import org.apache.hadoop.mapreduce.Reducer;
import org.apache.hadoop.mapreduce.lib.input.FileInputFormat;
import org.apache.hadoop.mapreduce.lib.output.FileOutputFormat;

public class Armstrong {

    // MAPPER
    // Input:  one number per line
    // Output: key = number (Text), value = "YES" or "NO" (Text)
    public static class ArmstrongMapper
        extends Mapper<LongWritable, Text, Text, Text> {

        // Helper: check if n is Armstrong number
        private boolean isArmstrong(int n) {
            String digits = String.valueOf(n);
            int power = digits.length();  // number of digits
            int sum = 0;

            for (char c : digits.toCharArray()) {
                int d = Character.getNumericValue(c);
                sum += (int) Math.pow(d, power);
            }

            return sum == n;
        }

        @Override
        public void map(LongWritable key, Text value, Context context)
            throws IOException, InterruptedException {

            String line = value.toString().trim();
            if (line.isEmpty()) return;

            try {
                int num = Integer.parseInt(line);
                String result = isArmstrong(num) ? "YES" : "NO";
                context.write(new Text(String.valueOf(num)), new Text(result));
            } catch (NumberFormatException e) {
                // skip
            }
        }
    }

    // REDUCER — pass through
    public static class ArmstrongReducer
        extends Reducer<Text, Text, Text, Text> {

        @Override
        public void reduce(Text key, Iterable<Text> values, Context context)
            throws IOException, InterruptedException {

            for (Text val : values) {
                context.write(key, val);
                break;
            }
        }
    }

    // DRIVER
    public static void main(String[] args) throws Exception {
        Configuration conf = new Configuration();
        Job job = Job.getInstance(conf, "Armstrong Number");

        job.setJarByClass(Armstrong.class);
        job.setMapperClass(ArmstrongMapper.class);
        job.setReducerClass(ArmstrongReducer.class);

        job.setOutputKeyClass(Text.class);
        job.setOutputValueClass(Text.class);

        FileInputFormat.addInputPath(job, new Path(args[0]));
        FileOutputFormat.setOutputPath(job, new Path(args[1]));

        System.exit(job.waitForCompletion(true) ? 0 : 1);
    }
}
```

## SECTION 9 — Viva Questions and Answers

**Q1: What is MapReduce?**

- Programming model for parallel processing of large datasets across a cluster
- Two user-defined phases: Map (transform input to intermediate key-value pairs) and Reduce (aggregate intermediate pairs)
- Framework handles: splitting input, scheduling tasks, shuffle/sort, fault tolerance
- Developer writes only map() and reduce() methods

**Q2: What is MPP (Massive Parallel Processing)?**

- Multiple processors/nodes simultaneously process different portions of the same dataset
- MapReduce implements MPP — many Mappers run in parallel on different data splits
- Enables processing of petabyte-scale data by horizontal scaling
- Contrast: single machine processes sequentially, bottlenecked by hardware

**Q3: What are the components of the YARN model?**

- ResourceManager (Master): Scheduler + ApplicationsManager — manages cluster resources
- NodeManager (each worker node): manages local resources, launches Containers
- ApplicationMaster (per job): negotiates resources, coordinates tasks
- Container: unit of CPU+RAM allocation where tasks execute

**Q4: What are the components of Hadoop and their working?**

- HDFS: stores data as blocks across DataNodes, NameNode manages metadata
- MapReduce: processes data in Map (parallel transform) → Reduce (aggregation) phases
- YARN: ResourceManager allocates Containers, NodeManagers run tasks
- Common: shared libraries (Hadoop utilities, configuration, serialization)

**Q5: What is Big Data? What are the V's?**

- Data too large/fast/complex for traditional tools
- Volume (size), Velocity (speed), Variety (types), Veracity (accuracy), Value (usefulness)

**Q6: What is the difference between Velocity and Veracity?**

- Velocity: speed at which data is generated and must be processed (stock tickers, IoT sensors, social feeds)
- Veracity: reliability and trustworthiness of data (incomplete records, fake data, measurement errors)

**Q7: What does the Mapper class do?**

- Processes one input split (logical portion of input file)
- Called once per input record (key-value pair from RecordReader)
- User overrides map() method — defines transformation logic
- Emits zero or more intermediate key-value pairs via context.write()
- Output stored on local disk (not HDFS) — temporary

**Q8: What does the Reducer class do?**

- Receives all values grouped under same key after shuffle and sort
- User overrides reduce() method — defines aggregation logic
- Called once per unique key with an Iterable of all values for that key
- Emits final output to HDFS via context.write()

**Q9: What is the role of the Driver?**

- Configures and submits the MapReduce job to the cluster
- Sets: jar class, mapper class, reducer class, output key/value types, input/output paths
- Calls job.waitForCompletion() to submit and monitor

**Q10: What is a Combiner? Why is it used?**

- Optional local Reducer that runs on Mapper output before shuffle
- Reduces amount of data transferred over network during shuffle phase
- Only valid when operation is commutative and associative (sum, count — yes; average — no)
- Also called local reducer or mini-reducer

**Q11: What is a Partitioner?**

- Determines which Reducer receives which key
- Default: hash(key) % numberOfReducers
- Ensures all values for same key go to same Reducer
- Can be customized for load balancing

**Q12: What is Shuffle and Sort?**

- Shuffle: framework transfers Mapper intermediate output to correct Reducer nodes over network
- Sort: all key-value pairs arriving at a Reducer are sorted by key before reduce() is called
- Most network-intensive phase of MapReduce
- Fully automatic — developer does not write any shuffle/sort code

**Q13: What is the difference between YARN and Hadoop v1 resource management?**

|Feature|Hadoop v1|YARN (v2)|
|---|---|---|
|Master for resources|JobTracker|ResourceManager|
|Worker for tasks|TaskTracker|NodeManager|
|Task management|JobTracker|ApplicationMaster (per job)|
|Resource unit|Fixed Map/Reduce slots|Dynamic Containers|
|Scalability|~4000 nodes|Tens of thousands of nodes|
|Non-MR workloads|Not supported|Supported (Spark, Tez, Flink)|

**Q14: What is the input to Mapper and output of Reducer in Word Count?**

- Mapper input: (byte offset, line text) — e.g., (0, "hello world hello")
- Mapper output: (word, 1) — e.g., (hello, 1), (world, 1), (hello, 1)
- Reducer input: (word, [1,1,1,...]) — e.g., (hello, [1,1,1])
- Reducer output: (word, count) — e.g., (hello, 3)

**Q15: Where is MapReduce output stored?**

- Output written to HDFS in the output directory specified in Driver (args[1])
- Output file: `/output_path/part-r-00000` (one file per Reducer, default 1 Reducer)
- View with: `hdfs dfs -cat /output/part-r-00000`
- Output directory must NOT exist before job runs — Hadoop throws error if it exists

**Q16: What is the Mapper type signature and what do the 4 type parameters mean?**

- `Mapper<KEYIN, VALUEIN, KEYOUT, VALUEOUT>`
- KEYIN: input key type (usually LongWritable — byte offset of line)
- VALUEIN: input value type (usually Text — the line content)
- KEYOUT: output key type (what mapper emits as key)
- VALUEOUT: output value type (what mapper emits as value)

**Q17: Why can't you run a MapReduce job if the output directory already exists?**

- Hadoop prevents overwriting existing output to avoid accidental data loss
- Must delete output directory before re-running: `hdfs dfs -rm -r /output`
